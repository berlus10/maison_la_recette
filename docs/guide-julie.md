# Guide de mise à jour pour Julie

Ce document sert à guider les mises à jour du contenu du site.

## Contenu éditable
- expériences
- avis
- À propos

## Mode de mise à jour
- via Sanity si le studio est actif
- sinon via JSON de démonstration

## Bonnes pratiques
- garder un ton chaleureux
- éviter les longues pages trop denses
- garder les textes lisibles et accessibles
